# 🌫️ Дымок

**Дымок** — механика кальяна на сервере **NEBULA**.

Здесь собрана основная техническая информация: как получить жижу для кальяна и как использовать её дальше.

---

## ⚙️ Как Сделать Жижу Для Кальяна

Для начала нужен **Котёл С Водой**.
После этого в котёл нужно по очереди бросить:

- 💎 **Алмаз**
- 🌿 **Блок Сушёной Ламинарии**
- 🔥 **Огненный Порошок**

После правильного смешивания выпадает предмет:

🧪 **Жижа Для Кальяна**

---

## 🧪 Что Делать Дальше

Полученную **Жижу Для Кальяна** нужно положить в **Зельеварку**.
После этого её можно использовать для работы механики кальяна.
